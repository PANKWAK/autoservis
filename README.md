# Autoservis Kolář

Statická verze webu pro GitHub Pages.

Postup:

1. Nahrajte obsah této složky do GitHub repozitáře.
2. V nastavení repozitáře otevřete Pages.
3. Jako zdroj vyberte větev a složku, ve které leží `index.html`.
4. Uložte nastavení a počkejte na publikovanou adresu.

Soubor `index.html` musí zůstat vedle `styles.css` a složky `assets`.
